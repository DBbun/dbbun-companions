# DBbun Companions

A collection of DBbun-generated companions built from documents, images, papers, patents, articles, and other source materials.

These companions may include:
- simulators
- synthetic datasets
- generated documentation
- figures and visual outputs
- scenarios and related artifacts

## About

DBbun turns static content into deeper, more explorable outputs.

Instead of leaving a source as something only to read or view, DBbun can generate a companion around it that supports inspection, simulation, scenario exploration, and additional analysis.

This repository contains selected public examples.

## Notes

DBbun companions are generated artifacts and may vary in structure and scope depending on the source material.
